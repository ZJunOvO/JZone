# JZone 歌词系统 PRD

## 1. 目标

在不依赖在线歌词服务的前提下，让用户能够在 JZone 内完成歌词导入、制作、校时、保存与播放跟随，形成从创作到聆听的完整闭环。

本功能直接接入正式项目，不建立 Lab 版本。开发基于独立分支进行，稳定分支保持可回退。

## 2. 产品原则

1. **同一份歌词，多处复用**：上传流程、歌曲编辑、创作工作台和播放页共用一套数据与编辑组件。
2. **先保证可用，再增加精度**：第一版完整支持纯文本、行级 LRC 与 TTML 导入/播放；逐字歌词制作延后，不用虚假动画冒充逐字时间。
3. **移动端优先**：录音创作者可以只用手机完成粘贴、分行、逐行打点、偏移校正和预览。
4. **播放不中断**：歌词视图是全屏播放页的内容状态，不新建独立播放器，也不改变底部评论、记忆卡片、待播清单三个入口。
5. **离线友好**：歌词是小型元数据，存入 Supabase，并按歌曲与版本长期缓存；不占用 COS 流量。
6. **性能可降级**：高性能设备使用 Apple Music 风格动效，低性能设备和减少动态效果模式退回稳定的行级滚动。

## 3. 用户入口

### 3.1 新上传歌曲

- 上传编辑区增加“歌词”模块，默认折叠。
- 支持上传 `.lrc`、`.txt`、`.ttml`，也可粘贴文本或从零创建。
- 保存歌曲时一并保存歌词；歌词保存失败不能让已经成功上传的音频消失，应明确提示并允许稍后补录。

### 3.2 已有歌曲

- 歌曲“更多”菜单对所有可播放用户显示“查看歌词”。
- 仅歌曲所有者显示“添加歌词”或“编辑歌词”。
- 编辑歌曲信息弹窗复用同一歌词编辑器入口，不复制解析和保存逻辑。

### 3.3 创作工作台

- 增加“歌词制作”入口，展示我拥有且可编辑的歌曲。
- 可继续未完成草稿，也可选择已有歌曲制作或修订歌词。
- 编辑草稿按歌曲隔离，切换页面后仍保留。

### 3.4 全屏播放页

- 封面区域支持切换到歌词视图；“更多”菜单提供显式入口。
- 当前歌词随播放进度聚焦，点击歌词行跳转到对应时间。
- 无歌词时展示克制空状态；歌曲所有者可直接进入添加歌词。
- 歌词切换不重建音频元素，不影响播放、进度、队列和共享动画。

## 4. 编辑器交互

### 4.1 输入模式

- 上传文件：LRC、纯文本、TTML。
- 粘贴文本：自动识别 LRC，否则按纯文本处理。
- 从零创建：按行输入。

### 4.2 行级校时

- 播放/暂停与进度拖动。
- 大尺寸“标记当前行”按钮，记录当前播放时间并自动前进到下一行。
- 上一行、下一行、撤销上次打点、清除本行时间。
- 点击任意行跳转试听。
- 全局偏移量调整，适合整体提前或延后。
- 时间必须单调；冲突时提示并允许自动整理。

### 4.3 预览与保存

- 编辑与播放预览可切换，预览使用正式歌词渲染器。
- 保存前校验空内容、非法时间、超出歌曲时长和格式解析错误。
- 自动保存本地草稿；成功写入后清除对应草稿。

## 5. 数据模型

歌词使用 `song_lyrics` 一对一表：

- `song_id`：歌曲主键，同时作为歌词主键。
- `format`：`plain`、`lrc`、`ttml`。
- `source`：`upload`、`embedded`、`editor`。
- `raw_content`：原始歌词，保留可再次编辑性。
- `normalized_content`：标准化结构，可空，用于加速渲染。
- `offset_ms`：全局偏移。
- `checksum`、`version`：缓存更新与并发覆盖判断。
- `created_at`、`updated_at`。

权限沿用歌曲可见性：能看见歌曲的用户可读歌词，只有歌曲所有者可新增、更新或删除。

## 6. 格式策略

- **纯文本**：只展示，不跟随时间。
- **LRC**：第一版制作格式，支持行级时间与偏移。
- **TTML**：支持导入、保存和高质量逐字播放；第一版不承诺在手机端从零制作逐字时间。
- **内嵌歌词**：作为第二阶段输入能力，优先读取 MP3、FLAC、M4A 中已有的歌词标签，不做联网搜索。

## 7. 动效与性能

- 首选 AMLL 官方渲染能力实现 Apple Music 风格歌词。
- 普通 LRC 只执行行级聚焦与滚动，TTML 才启用逐字进度。
- 页面不可见、歌词视图关闭或组件卸载时停止动画与监听。
- `prefers-reduced-motion`、低帧率或兼容性不足时自动切换轻量渲染器。
- 歌词缓存按 `song_id + checksum` 更新，避免每次打开播放器重复拉取与解析。

## 8. 第一版验收标准

1. 新上传和已有歌曲均能添加、编辑、删除歌词。
2. 创作页可以选择歌曲制作行级 LRC，并在离开后恢复草稿。
3. 播放页能在封面与歌词间切换，点击行可跳转且播放不中断。
4. LRC、纯文本和 TTML 输入均有正确结果；无歌词、解析失败、网络失败状态不混淆。
5. 私有歌曲歌词不会泄露，非所有者无法修改。
6. 360px 与 390px 手机视口无溢出，Edge/Chromium 真机保持可操作。
7. 构建、类型检查、歌词专项 smoke 与现有播放器回归测试通过。

## 9. 延后范围

- 在线歌词搜索或自动匹配。
- 从零制作逐字/音节级 TTML。
- 多语言对照、罗马音和翻译轨道。
- 评论绑定歌词行。
- 歌词协作编辑与版本历史界面。
