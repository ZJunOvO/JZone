## 记录格式

每条备忘按以下格式维护：

- 状态：`待讨论` / `已确认` / `进行中` / `已完成` / `延后`
- 优先级：`P0` 立即影响核心体验，`P1` 近期体验完整性，`P2` 中期增强，`P3` 长期想法
- 所属页面：现在就听 / 播放页 / 资料库 / 创作 / 我的 / 全局 / 后端
- 核心需求：一句话说明用户真正想完成什么
- 初步方案：当前倾向方案，后续可以更新
- 验收要点：完成后回头检查什么

- 核心需求：从封面进入播放页或详情页时有更自然的视觉连续性。
- 完成方案：一级 Tab 路由改为只动画内容真实 DOM 的 260ms 低位移转场，Mini 播放器和底部 Tab 保持单实例常驻，避免浏览器旧/新快照造成重复组件、折射丢失和卡顿。Mini 播放器容器从实时边界以单一可中断进度派生四边 clip-path，560ms 铺满视窗、380ms 沿原路径收拢。全屏封面与 Mini 落地分别使用峰值约 0.55% / 0.72% 的 480ms 临界阻尼冲量曲线，从 `scale=1` 连续起步，不再预压缩或补播缩放关键帧。歌单/专辑封面到合集详情继续使用稳定对象 ID 的 Framer Motion 共享布局。
