# JZone 歌词体验、Bento 稳定性与紧凑 Dock Tasks

## 目标

在不削弱现有动效的前提下，解决 Bento 快速切换的双卡顿，统一紧凑模式下的底部 Tab 与 mini 播放器，并把播放页歌词与歌词制作流程重构为符合直觉的完整体验。

## 产品原则

- 状态切换只有一个视觉结论，旧动画必须可取消，不能排队补播。
- 紧凑模式是一套统一 Dock 几何系统，不是单独缩窄底部 Tab。
- 封面本身就是封面/歌词切换入口，不显示“查看歌词”悬浮按钮。
- 歌词状态保持空间连续：大封面缩至顶部，标题与艺人位于封面右侧，歌词占据其下方至进度条之间的区域。
- 歌词制作围绕“暂停后编辑”设计，新增行和标记行都会暂停播放。
- 对唱与和声由用户逐行标记；播放器只忠实呈现，不自动猜测演唱者。
- 面向用户的界面不暴露开发术语、格式实现和重复说明。

- [x] 当前行为最后一行时，标记成功后自动创建下一空白行并选中，不能重复覆盖上一句。
- [x] 保留撤销标记、前后行、跳转试听和偏移能力。

- [x] 本地草稿、上传流程和已有歌曲编辑继续复用同一编辑器。
