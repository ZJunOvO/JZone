## 执行原则

- 保留四个一级页面：现在就听、资料库、创作、我的。
- 不改资料库 Bento 视图和现有播放页核心视觉。
- 旧字段、旧数据库和旧调用入口保持可用，新能力采用向后兼容方式接入。
- 每个批次完成后运行 `npm run typecheck`、`npm run build` 和现有 smoke 测试。
